# ساخت APK با GitHub Actions

## بارگذاری در GitHub
1. یک مخزن جدید در GitHub بسازید (ترجیحاً Private).
2. فایل‌های داخل این بسته را Extract کنید.
3. تمام محتویات پوشه استخراج‌شده را در ریشه مخزن GitHub بارگذاری کنید؛ خود پوشه والد را به‌صورت یک زیرپوشه بارگذاری نکنید.
4. پس از Commit، وارد تب Actions شوید.
5. گردش‌کار Build APK به‌صورت خودکار اجرا می‌شود. برای اجرای دستی نیز از Run workflow استفاده کنید.

## دریافت APK
پس از پایان موفق اجرا:
1. اجرای سبز با عنوان Build APK را باز کنید.
2. پایین صفحه، بخش Artifacts را پیدا کنید.
3. فایل app-debug را دانلود و از حالت فشرده خارج کنید.
4. فایل app-debug.apk را روی گوشی نصب کنید.

## نکات مهم
- این برنامه یک پوسته WebView است و فایل HTML نسخه ۴٫۲ را داخل اپ اجرا می‌کند.
- اطلاعات در حافظه محلی برنامه ذخیره می‌شوند و با حذف داده‌های برنامه یا حذف خود برنامه ممکن است از بین بروند؛ مرتباً از بخش پشتیبان‌گیری خروجی بگیرید.
- قبل از استفاده واقعی، نصب، ثبت اطلاعات، بستن و بازکردن برنامه، پشتیبان‌گیری، بازیابی و چاپ PDF را آزمایش کنید.
- این پروژه در این محیط کامپایل نشده است؛ موفقیت ساخت نهایی باید از نتیجه GitHub Actions تأیید شود.
